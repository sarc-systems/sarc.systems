# Library image proposals — Systems — 2026-07-31

Librarian Mode C (research-only), scope extended for this run per explicit
user request ("fill in some photos of the Systems") to cover **System-type**
entries (physical hardware synthesizers, samplers, and studio effects units)
with `images: []`, instead of Mode C's usual person/group/organization
target. Proposal-only per the librarian agent's hard rules — **no image
files were downloaded or added**; every candidate below needs a human to
fetch, crop, and add it to the entry's bundle, then fill in `images:` using
the suggested fields.

Researched via Wikimedia Commons category/search pages and file-description
pages (`commons.wikimedia.org/wiki/File:…`), which is the accepted "exact
page where provenance can be verified" per CLAUDE.md. Every `source` below
is a Commons **file description page**, never a bare category page, a raw
file URL, or the original Flickr photostream — the Commons file page is
what actually states the license and author, so that's what should be cited
as `source`. Where the underlying photo originates on Flickr, `credit`
names the photographer and the Commons file page (not Flickr) is the
`source`. (This session's WebSearch budget was exhausted partway through, so
research here proceeded via direct Wikimedia Commons category/search-API and
file-page fetches rather than general web search — the same source-quality
bar applies, it just narrowed the discovery tool.)

**On black-and-white preference:** CLAUDE.md's instruction to prefer
black-and-white when choosing between comparably-sourced options (in
anticipation of the site's B&W convention extending to Systems) applies
here, but essentially no genuine black-and-white candidates turned up for
this batch — unlike portraits, which often have real archival press/studio
photography, these hardware synths are almost all documented on Commons via
modern amateur/enthusiast digital photography (NAMM show floors, private
collections, museum visits with phone cameras), which is uniformly color.
The two exceptions with real historical/institutional weight — the 1964
first-commercial-Moog photo (Stearns Collection, University of Michigan) and
the 1989 Korg Poly-Six photo (Ken Eckert) — are noted below but not
confirmed B&W; a human should check before use. Per the task's own framing,
this is a preference between real options, not a reason to reject an
otherwise good, well-sourced color photo.

mostly Flickr transfers or "own work" uploads), 1 `permitted` (roland-d50,

1 `public-domain` (tonto, CC0), 1 flagged-alternate `unknown` (the

**25 entries on the target list not attempted** this run (listed above) —

several (bela/bela-gem/bela-gem-multi, adrenalinn, nonlinear-labs-c15,
synton-fenix-i/ii, synton-syrinx) are flagged in advance as likely to have
little or no Commons coverage given how small/recent their manufacturers are.
