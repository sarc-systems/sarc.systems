# Library image proposals — 2026-07-31

Mode C (research-only) pass over the structural report's "Person/group/organization
entries with no image" list. Proposal-only per the librarian agent's hard rules —
**no image files were downloaded or added**; every candidate below needs a human
to fetch, crop, and add it to the entry's bundle, then fill in `images:` using
the suggested fields.

Researched via Wikimedia Commons category/search + file-description pages
(`commons.wikimedia.org/wiki/File:…`), which is the accepted "exact page where
provenance can be verified" per CLAUDE.md. Every `source` below is a Commons
**file description page**, never a bare category page, a raw file URL, or the
original Flickr photostream — the Commons file page is what actually states the
license and author, so that's what should be cited as `source`. Where the
underlying photo originates on Flickr, `credit` names the photographer and the
Commons file page (not Flickr) is the `source`.

Portraits favor black-and-white where a comparably-sourced b&w option existed;
most available options for contemporary/still-living figures are color concert
or press photography, noted per entry.
