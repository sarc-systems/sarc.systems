{{- /* Resolve which registered Collection (data/library/collections.yaml) a Library page belongs to — either a Collection's own section index page or one of its Entries — by longest-prefix match of the page's content-relative File.Path against each Collection's source.section (adapter: hugo only). One resolution mechanism used everywhere a Library template needs "which Collection is this" — see docs/library-v2.md § 2.2/§ 3/§ 11. Call: {{ $coll := partial "library-resolve-collection.html" . }} Returns the matched Collection dict (data/library/collections.yaml shape). The Library root itself (content/library/_index.md — depth 1 under content/library/, i.e. no Collection claims it) is not a row in the registry — it's the implicit meta-Collection, not one of its own children — so it resolves to a synthetic dict with `source.adapter: "root"` instead. Fails the build for anything else under the library section that no Collection's source.section prefixes (a genuinely orphaned page). */ -}} {{- $page := . -}} {{- $registry := hugo.Data.library.collections -}} {{- $coll := dict -}} {{- $bestLen := 0 -}} {{- range $registry -}} {{- if and (eq .source.adapter "hugo") .source.section (hasPrefix $page.File.Path (printf "%s/" .source.section)) (gt (len .source.section) $bestLen) -}} {{- $coll = . }}{{ $bestLen = len .source.section -}} {{- end -}} {{- end -}} {{- if not $coll.id -}} {{- if eq $page.File.Path "library/_index.md" -}} {{- /* The meta-Collection offers Catalog only for now — no Map or Images at the Library root. This is the same per-Collection `views` shape a registry row carries (data/library/collections.yaml), supplied here because the root is not a registry row. */ -}} {{- $coll = dict "id" "library" "title" $page.Title "color" "" "source" (dict "adapter" "root" "section" "library") "views" (dict "enabled" (slice "catalog") "default" "catalog") -}} {{- else -}} {{- errorf "library-resolve-collection.html: no Collection in data/library/collections.yaml matches %q" $page.File.Path -}} {{- end -}} {{- end -}} {{- return $coll -}}
