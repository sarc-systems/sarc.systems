{{- /* The one centralized specific-type -> public-type mapping for ONE Collection's vocabulary (see library-vocab.html, data/library.yaml's `types`/`public_types`, and CLAUDE.md § Library "Public Type vs Specific Type"). Returns {styles, typeOf}: `styles` is a dict keyed by public_type (each {public_type, label, color, shape, order, hub?}); `typeOf` is a dict keyed by specific type, valued with its public_type string. Pure function of its input (a vocabulary dict — data/library.yaml's shape — resolved per-Collection via library-vocab.html, NOT always hugo.Data.library) — always call via partialCached, with a cache key that varies by WHICH vocabulary, so two Collections sharing a vocabulary reuse one computation, but two different vocabularies never collide on a fixed key and silently return each other's styles: {{ $lib := partial "library-vocab.html" $coll }} {{ $pt := partialCached "library-public-types.html" $lib (printf "library-public-types-%s" ($coll.vocabulary | default "library")) }} Every caller (list.json, library-filters.html, library-record.html, library-image-index.html, library-entry-shelves.html, library-validate.html, library-works.html, library-related.html, single.html) resolves through this one partial — never a second copy of the mapping. */ -}} {{- $lib := . -}} {{- $styles := dict -}} {{- range $lib.public_types -}} {{- if not .color }}{{ errorf "Library: public_type %q has no color defined" .public_type }}{{ end -}} {{- if not .shape }}{{ errorf "Library: public_type %q has no shape defined" .public_type }}{{ end -}} {{- $styles = merge $styles (dict .public_type .) -}} {{- end -}} {{- $typeOf := dict -}} {{- range $lib.types -}} {{- if not .public_type }}{{ errorf "Library: type %q has no public_type mapping in its vocabulary" .type }}{{ end -}} {{- if not (index $styles .public_type) }}{{ errorf "Library: type %q maps to unknown public_type %q (not in its vocabulary's public_types)" .type .public_type }}{{ end -}} {{- $typeOf = merge $typeOf (dict .type .public_type) -}} {{- end -}} {{- return (dict "styles" $styles "typeOf" $typeOf) -}}
