Introduced by [Stafford Beer](/library/research/stafford-beer/) in *[Brain of the Firm](/library/research/brain-of-the-firm/)* (1972), the Viable System Model describes the organizational structure any autonomous, self-sustaining system needs, built by analogy to the brain and nervous system's own layered control of a body. Five subsystems recur at every scale: System 1 carries out an organization's core operational activities; System 2 coordinates and dampens conflict between them; System 3 allocates resources and oversees System 1 from inside the organization; System 4 looks outward, monitoring the environment and proposing adaptation; and System 5 sets policy, balancing System 3's internal focus against System 4's external one. Because a viable system's own operational units are themselves viable systems built the same way, the model nests recursively at every organizational scale, from a single team to a national economy — the structure [Project Cybersyn](/library/research/project-cybersyn/) applied to Chile's economy in 1971–73.
