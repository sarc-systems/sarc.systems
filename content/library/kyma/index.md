First written by Carla Scaletti in 1986 in Smalltalk, Kyma treats everything in a piece — from a single sound's internal structure to the composition as a whole — as a "Sound Object," with no fixed distinction between instrument and score, run on Symbolic Sound's dedicated digital signal processing hardware.
